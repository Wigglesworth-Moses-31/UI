## ⏱️ 07:05 – 08:03 · 🧩 Node.js Teaches You to *Build* Servers

🔑 **Key points**
- 🧑‍💻 Java, .NET, Python, PHP developers **use** some server to run their applications.
- 🏗️ *"Majority people don't learn how to build servers"*; they *"only use"* them (as said).
- 🟢 With Node.js **you can build your own server**.

```
  ☕ Java / 🟦 .NET / 🐍 Python / 🐘 PHP dev ──► USES an existing server
  🟢 Node.js dev                           ──► can BUILD the server
```

---

## ⏱️ 08:03 – 09:01 · 🧩 CLI Tools, Server-Side Scripts & Our Purpose

🔑 **Key points**
- ⌨️ **Command-line tools:** like the Windows **command prompt**, where you create folders and run programs. Such tools can be built with Node.js.
- 📜 Also used for **server-side programming** and **server-side scripts**.
- 🎯 **Why we install it in this course:** to build **web applications**.

🧠 **Hook:** *"Why install Node.js?" → because we build web apps, and Node.js lets us build web apps.*
