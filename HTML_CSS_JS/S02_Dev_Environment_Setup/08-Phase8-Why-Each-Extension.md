## ⏱️ 41:16 – 43:14 · 🧩 🖥️ Live Server: Run From a Server ⭐

🔑 **Key points**
- 🏫 School/college/YouTube habit: create a page, save it in a folder, **double-click** to open it. *"That will not work out in real time."*
- 🏢 Real time: **build a project → host it on a server → access it from the server**.
- 🔁 Practise the same way on your device, so it behaves like real time. *"We will not run our web applications directly. We have to run them from a server."*

```
  ❌ School way:     📄 page.html ──double-click──► 🌐 browser
  ✅ Real-time way:  📁 project ──► 🖥️ server (Live Server) ──► 🌐 browser
```

- 🔍 Install: **Extensions → search "Live Server"** → many results share the name → pick the one by **the author given** (🎬 **Ritwick Dey**) → **Install**.
- 👀 On the instructor's PC it's already installed, so it shows **Uninstall** instead.
- 🎬 **Look-alikes in the same search (42:25):** `Live Server (Five Se…` by Yannick, `Live Server Preview` by negokaz, `Live Preview` by Microsoft, `XVBA - Live Server …`, `html-live-server`, `php-live-server`. That is why the author name matters.
- 🎬 The extension page describes it as: *"Launch a development local Server with live reload feature for static & dynamic pages"*.

> 🎬 **Seen on screen (42:33):** the Live Server page shows the buttons **Disable** and **Uninstall** (plus *Auto Update*), with no Install button. So the transcript's "it is uninstalled" means the button reads **Uninstall** because the extension is already installed.

🧠 **Hook:** *Applications run on a server, so practise on a server.*

## ⏱️ 43:14 – 44:20 · 🧩 🗂️ VS Code Icons

🔑 **Key points**
- 🏷️ Official, from the **VS Code Icons Team** (no individual author).
- 🎬 **Seen on screen (43:23–43:55):** search text typed is `vscode-icons`; the extension is named **vscode-icons**, publisher **VSCode Icons Team**, tagline *"Icons for Visual Studio Code"*. Its page has a **Set File Icon Theme** button next to Disable / Uninstall.
- 📚 A project has **hundreds of files** of different types (HTML, CSS, JavaScript…). If all look alike, you must check each **extension** carefully.
- ✅ With VS Code Icons: HTML files get an **HTML icon**, CSS files a **CSS icon**, so you **identify files easily**.

## ⏱️ 44:57 – 46:05 · 🧩 💡 IntelliSense for CSS Class Names

🔑 **Key points**
- 🧠 Learning HTML/CSS means **many things to remember**.
- 💡 IntelliSense gives **suggestions while you type**; you **choose** from them.
- ✅ Advantage: you **don't need to remember everything**; it makes HTML/CSS *"a little easy"*.
- 🎬 **Seen on screen (45:07–45:39):** searched by typing `intelli`; the one opened is **IntelliSense for CSS class names in HTML** by **Zignd**. Its description: *"CSS class name completion for the HTML class attribute based on the definitions found in your workspace."* So the suggestions it adds are specifically **CSS class names** inside the HTML `class` attribute.
