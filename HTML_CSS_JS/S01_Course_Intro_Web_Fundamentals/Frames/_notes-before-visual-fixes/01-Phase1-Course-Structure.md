# 1️⃣ Phase 1 · Course Structure & the Frontend Stack

**⏱️ 01:41 – 09:59** · 📂 S01 Course Intro & Web Fundamentals · [⬅️ Overview](00-Overview.md) · [Next ➡️](02-Phase2-Learning-Habits-Jobs.md)

> 🚫 **Mostly non-technical** (batch logistics). The **stack list** (03:58 – 06:48) is the technical part worth noting.

---

## ⏱️ 01:41 – 03:03 · 🧩 Who Is in This Batch 🚫

🔑 **Key points**
- 🎓 The course is **UI Full Stack with React.js**.
- 👥 Learners from **Python, Java, .NET** and other backgrounds also attend this batch to learn UI.
- 🎯 The batch is aimed at **everyone learning frontend**, whatever their background.

---

## ⏱️ 03:03 – 03:58 · 🧩 Frontend Is Common, Backend Changes ⭐

🔑 **Key points**
- 🖥️ **UI (user interface) is common for everyone.** Only the backend differs by stack.
- 🔁 Full-stack learners first spend the opening sessions on the **complete frontend**, then shift to their backend.
```
              🎨 FRONTEND ── common for every full stack
                     │
     ┌───────────────┼───────────────┬───────────────┐
     ▼               ▼               ▼               ▼
  🟢 UI FS        ☕ Java FS      🟦 .NET FS      🐍 Python FS
  MongoDB         own             own             own
  Express.js      frameworks      frameworks      frameworks
  Node.js         + databases     + databases     + databases
```

🧠 **Hook:** *Same face (UI), different engines (backend).*

---

## ⏱️ 03:58 – 05:00 · 🧩 The Frontend Topics

🔑 **Key points**
- 📚 Frontend topics in this course:
```
  1️⃣ HTML ──► 2️⃣ CSS ──► 3️⃣ Bootstrap ──► 4️⃣ Tailwind ──► 5️⃣ JavaScript
                                                              │
                         (only if your course includes it) ──►  ⚛️ React + 🔷 TypeScript
```
- ⚛️ **React + TypeScript is not for everyone.**
  - 🟢 UI Full Stack → complete React **and** TypeScript.
  - ☕🐍 Java / Python full stack → React only if their course has it.
  - Otherwise this frontend session **ends after JavaScript**.

---

## ⏱️ 05:00 – 06:01 · 🧩 Duration & Timing 🚫

🔑 **Key points**
- 🕘 Frontend runs **9:00 – 11:00 a.m.** for **two and a half months**.
- ✅ In that time: HTML, CSS, Bootstrap, Tailwind and JavaScript.
- ➡️ After that, each learner moves to their own backend.
- 🔗 A community link is shared at the end for course content.

---

## ⏱️ 06:01 – 07:01 · 🧩 Backend per Stack

🔑 **Key points**
| 🧱 Stack | 🗄️ Database | 🔀 Middleware | 🖥️ Server side |
|---|---|---|---|
| 🟢 UI Full Stack | **MongoDB** | **Express.js** | **Node.js** |
| ☕ Java · 🟦 .NET · 🐍 Python | Their own | Their own frameworks | Their own |

- 🙋 UI Full Stack queries go to this instructor; Java/Python queries go to their own trainers.

---

## ⏱️ 07:01 – 08:00 · 🧩 Why Everyone Now Learns Frontend in Depth

🔑 **Key points**
- 🕰️ **Earlier:** Java/.NET/Python learners got a separate, short HTML/CSS batch with only an outline of what they needed.
- 📈 **Now:** *"Companies are asking a lot of questions on front-end."* You need **in-depth** frontend knowledge.
- 🎯 Goal: crack interviews **at any level of experience**.
```
  BEFORE  ☕ Java dev ──► 📄 frontend outline only ──► backend
  NOW     ☕ Java dev ──► 🎨 complete end-to-end frontend ──► backend
```

---

## ⏱️ 08:00 – 09:59 · 🧩 How the Classes Will Run 🛠️

🔑 **Key points**
- 🧭 First an overview of **why** you need HTML, CSS, etc.
- 🔁 Pattern for every topic:
```
  🎧 One topic explained ──► 📝 One task given to you ──► ⌨️ You do it hands-on
```
- 💻 Some **hands-on sessions in class**: bring a laptop and **code along** with the instructor, then show the result.
- 🎯 Not every topic, only **important concepts** are coded live in class.
- 🏆 Doing it together in class gives *"perfection on what you are learning."*

🧠 **Hook:** *Learn → task → hands-on. No passive watching.*
