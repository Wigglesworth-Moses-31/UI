## ⏱️ 1:02:30 – 1:03:00 · 🧩 The Web Comprises Many Things ⭐

🔑 **Key points**
- 🕸️ People usually know only one thing, the **website**. But the web contains much more:
```
                          🕸️ WEB
                            │
  ┌─────────┬─────────┬─────┴─────┬──────────┬───────────┬──────────┐
  ▼         ▼         ▼           ▼          ▼           ▼          ▼
 🌐 Web-   🧩 Web     📝 Blogs   💬 Micro-  📚 Wikis    🎙️ Pod-    🔲 Widgets
   sites    apps                  blogs     (Wikipedia)  casts
```
- ❗ **Web is not website.** Not everything on the web is a website.

🧠 **Hook:** *Web = sites + apps + blogs + microblogs + wikis + podcasts + widgets.*

---

## ⏱️ 1:03:00 – 1:04:13 · 🧩 Spotify & YouTube = "Podcasters" 🎧

🔑 **Key points**
- ❓ *"What do you call Spotify? A website?"* → Instructor: **No, it's a podcaster.**
- 📡 Why: you can play a song on your laptop **or broadcast it** to a remote TV or Bluetooth speakers.
```
  🎵 Spotify / ▶️ YouTube
      ├──► 💻 play on laptop
      ├──► 📺 broadcast to a TV
      └──► 🔊 broadcast to Bluetooth speakers
            ⇒ 🎙️ "podcaster", not a website (as taught)
```
- 🗣️ Calling YouTube a "website" makes people see you as *"software illiterate"* (instructor's words).

## ⏱️ 1:04:13 – 1:05:00 · 🧩 Know What It Is, Not Just How to Use It

🔑 **Key points**
- 🧑‍🎓 Basic learners **use** things without knowing **what they are**.
- 🎤 Interviews check **how much you know about it**, not only how much you can do with it. They want **technically correct** knowledge.
- ⏭️ The difference between **website and web application** and the others will be covered one by one.
