## ⏱️ 24:48 – 26:00 · 🧩 Netflix: Browser vs App 🎬

🔑 **Key points**
- ❓ *"What is the advantage of watching YouTube/Netflix on the **app** instead of the **browser**?"*
- ✅ **Answer (as taught):** a distributed app can **keep a lot of information offline**, e.g. **downloaded videos** to watch later. The instructor says this isn't possible in a browser.
```
  📺 Netflix in a BROWSER  (🌍 web)           📲 Netflix APP  (🌐 distributed)
     └─ watch online                          ├─ 💾 download & keep offline
                                              └─ 🔄 updated info still comes online
```
