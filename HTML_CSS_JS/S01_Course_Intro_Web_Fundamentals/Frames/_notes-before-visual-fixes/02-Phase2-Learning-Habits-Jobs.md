## ⏱️ 10:55 – 12:03 · 🧩 Why Many Learners Lack Practical Skill 🚫

🔑 **Key points (instructor's experience)**
- 👨‍🏫 25 years training; 18th year at Naresh IT; has trained lakhs of people.
- 📉 His view: since **COVID**, fewer strong software engineers are coming out.
- 📺 Reason he gives: learners are used to **videos, PDFs and tutorials** and lack **practical implementation**.
- 📚 Xerox centres in Ameerpet (Hyderabad) still sell **handwritten notes** from earlier batches; students then wrote every program by hand from the board.

> 📝 The transcript says *"lacks of people"*; from context this is **lakhs**.

## ⏱️ 12:03 – 13:00 · 🧩 The Copy-Paste Problem 🚫

🔑 **Key points**
- 📋 Today: *"Upload on Google Classroom, I'll copy-paste."* Learners run copied code and think it's done.
- 📊 In campus drives, out of 100 candidates **only 1–2 get selected**; a company needing 10 people couldn't get 10.
- 🧠 *"When you write, it goes into your brain."*
```
  ❌  📋 Copy ──► ▶️ Run ──► "done"                         (no skill)
  ✅  👀 Watch ──► ✍️ Write by hand ──► ⌨️ Type it yourself ──► 🧠 retained
```

## ⏱️ 13:00 – 14:01 · 🧩 Paper-Syntax Interviews ⭐

🔑 **Key points**
- 📄 High-level company interviews may say: *"Write the syntax on paper and show me"*, before any laptop.
- ✍️ You don't need to write whole programs by hand, but **do** keep writing **definitions and FAQs** from class.

🧠 **Hook:** *If you can't write it on paper, you don't know it yet.*

---

## ⏱️ 14:01 – 17:10 · 🧩 Placements & Frontend Jobs 🚫

🔑 **Key points**
- 📸 The institute's **Instagram group** posts placements and requirements; this instructor posts mainly **frontend** roles.
- 🏢 Requirements come from client companies where **senior students already work**, often **not on Naukri**.
- 🎓 Typical criteria named: *any stream, any year passed out, any qualification*. **Skill** is what matters.
- 🧰 Skills named for these roles: **HTML, CSS, JavaScript, Bootstrap**, and **React + JavaScript**.
- 🗣️ Some placed students have weak English but strong technical skills; some got placed **before finishing the course**.
- 💰 About **3 LPA** is mentioned as a fresher package for these skills.

```
  🎯 Skill in HTML · CSS · JS · React  ══►  frontend job  (even before full-stack is done)
```
