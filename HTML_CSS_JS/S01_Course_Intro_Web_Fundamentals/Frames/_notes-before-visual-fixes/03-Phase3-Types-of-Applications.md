🔑 **Key points**
- ☕ Asked of Java learners: with Java you can build **desktop**, **web** and **distributed** apps.

## ⏱️ 19:30 – 20:11 · 🧩 🖥️ Desktop Application

🔑 **Key points**
- 🏥 **Example:** a single hospital with **no branches**, no online booking, no online consultation.
- 🗂️ It uses **one software** to record walk-in patients, billing and medicines.
- ✅ For this, **desktop applications are good**.

---

## ⏱️ 20:11 – 21:00 · 🧩 🌍 Web Application

🔑 **Key points**
- 🔌 Needed when you want to **connect over the internet**: book an appointment or consult a doctor online.
- 🏥 **Example:** open a **browser** (laptop or mobile), visit **Apollo Hospitals**, order medicine or book a doctor → that's a **web application**.

---

## ⏱️ 21:00 – 22:03 · 🧩 🌐 Distributed vs 📱 Mobile ⭐

🔑 **Key points**
- 📲 The **Apollo app** on your phone: will it work **without internet**? ❌ No → it is **not** a mobile app; it is **distributed**.
- 📱 **Mobile app (as taught)** = runs on the mobile and **doesn't need an internet connection**: phone book, camera, calendar, calculator.
- 🌐 **Distributed** = Amazon, Swiggy, Zomato, Uber, Facebook, Instagram.
```
  How do you reach it?
      │
      ├── 🧭 through a BROWSER ───────────────────────────► 🌍 WEB APP        (Apollo website)
      │
      └── 📲 an installed APP ──► needs internet?
                                   ├── ✅ yes ────────────► 🌐 DISTRIBUTED   (Swiggy · Uber · Instagram)
                                   └── ❌ no  ────────────► 📱 MOBILE        (calculator · camera)
```

🧠 **Hook:** *Installed + needs internet = distributed. Installed + offline = mobile.*

## ⏱️ 22:03 – 23:00 · 🧩 ⌚ IoT · 🤖 AI · 🎮 2D/3D Gaming

| 🧩 Type | 📌 Meaning (as taught) | 💡 Example |
|---|---|---|
