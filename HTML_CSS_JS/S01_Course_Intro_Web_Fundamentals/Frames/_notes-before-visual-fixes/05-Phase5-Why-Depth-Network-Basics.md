## ⏱️ 30:58 – 31:46 · 🧩 What Is a Computer Network? ⭐

🔑 **Key points**
- 📖 **Definition:** *A computer network is a group of computers connected with each other for sharing **information** and **resources**.*
```
   💻 ──┐
   💻 ──┼──🔗 connected──►  share  📄 information  +  🖨️ resources
   💻 ──┘
          = 🕸️ COMPUTER NETWORK
```

🧠 **Hook:** *Network = connected computers sharing info + resources.*
