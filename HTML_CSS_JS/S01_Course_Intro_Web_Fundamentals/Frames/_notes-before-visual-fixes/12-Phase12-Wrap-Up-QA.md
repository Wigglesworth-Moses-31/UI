## ⏱️ 1:11:11 – 1:12:49 · 🧩 Q&A 1: UI Full Stack Duration 🚫

🔑 **Answers given**
- 🗓️ **UI Full Stack = 5 months** in total.
- 🎨 Frontend: **2.5 months**. ⚛️ React: about **2 months**.
- 🗄️ Backend: **MongoDB, MySQL, Node.js, Express.js, jQuery** + **one project**.
- 🔀 After **complete JavaScript**, attend **React and backend in parallel**.

## ⏱️ 1:14:01 – 1:16:01 · 🧩 Q&A 3: Working Professionals 🚫

🔑 **Answers given**
- 🧱 **Up to JavaScript, attend only one session.** Parallel React/backend is **not suggested without JavaScript knowledge**.
- 🕘 The **9:00 a.m.** batch runs up to JavaScript (~2.5 months).
- 🌅🌙 React and backend batches mostly run at **7:30 a.m. or 7:30 p.m.** for working professionals.

## ⏱️ 1:16:01 – 1:18:35 · 🧩 Q&A 4: Java Developer in a UI Batch 🚫

🔑 **Answers given**
- ☕ Java/Python full-stack learners can attend **up to UI (React)** and keep **Java (Spring Boot)** for backend.
- 🔁 *"In every full stack, back-end changes. Front-end will be same."*
- 🟢 UI Full Stack backend = **MongoDB, MySQL, Node.js, Express.js**. Doing it also helps Java devs, as Java/.NET apps *"use MongoDB-like concepts"* these days.
