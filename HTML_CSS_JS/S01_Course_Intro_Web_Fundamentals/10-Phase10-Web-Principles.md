## ⏱️ 57:44 – 59:02 · 🧩 ♿ Accessibility: the J-Key Dot ⌨️

🔑 **Key points**
- ⌨️ On every keyboard the **J key has a small dot / bump**.
- 👆 Instructor's explanation: it's for **visually challenged** people. They touch it, know *"this is J"*, and start typing from there.
- 💡 So a keyboard is designed for visually challenged users. **A website must also be designed for visually and physically challenged people.**
- 🌍 In other countries, websites that don't follow these rules **can be banned**.

---

## ⏱️ 59:02 – 1:00:01 · 🧩 ♿ Audio Description on OTT 🎬

🔑 **Key points**
- 🎧 Netflix / Amazon Prime have **audio** and **subtitle** options. One audio option is **audio description**.
- 🗣️ It **narrates what's happening on screen**, e.g. *"two people are walking at a beach."*
- 👁️ Built for **visually challenged** viewers: they can follow the movie by listening, without seeing it.

---

## ⏱️ 1:00:01 – 1:01:03 · 🧩 ♿ Phone Accessibility Settings 📱

🔑 **Key points**
- 📌 Netflix keeps audio description because **they have to**: it is **according to the rules**.
- 📱 Every mobile has an **Accessibility** category. Without it, *"a mobile cannot be released into any country"* (as said).
- 📞 Examples: it **announces the caller's name** on an incoming call; you can say *"Dial this number"* and it dials.
- 🦾 These are facilities for **visually / physically challenged** users, not conveniences for others.
```
  ♿ ACCESSIBILITY IN REAL LIFE
   ├─ ⌨️ J-key dot ............... start typing by touch
   ├─ 🎬 Audio description ....... hear what's on screen
   └─ 📱 Phone accessibility ..... caller-name announce · voice dial
```

## ⏱️ 1:01:03 – 1:02:30 · 🧩 Standards Make You Industry-Ready ⭐

🔑 **Key points**
- 🚨 *"These are not technology-related advanced features. They are **mandatory** concepts."* Without them, a product cannot be released.
- 🎓 Problem with school/college learning: you learn the concept but **not its standards**, so you don't fit real-time work.
- 😤 In companies, seniors get irritated: *"Where did you learn? You don't know the standards."*
- ✅ Fix: **learn every technology according to its standards**, then implement it that way in real projects.
